bell02 の音程チェック

bell02(1番管 + ベル)を付けたホルンの入力インピーダンスを calcimp で計算し、RefHorn と同じ条件で比べた。右手補正あり。

要点

  • bell02 は試算。F 管の第2倍音を f' に対して −30 セントにし、オクターブの幅 3→6・4→8・6→12 を Bb・F とも +10 にする条件で、基本形と局所的な摂動1つを合わせ込んだ(⌀12 になる L = 1450 mm、リム ⌀300)。どの条件も ±1.1 セント以内。
  • Bb 管(f' = +15.9、a' = 442 Hz)。f' に対して Bb(第2倍音)−20.9、f −9.9、bb −13.6、bb' −4.4、d'' −32.7 セント。オクターブの幅は 3→6 が +9.9、4→8 が +9.2、6→12 が +9.9。
  • F 管(f' = +25.9、延長量 939.3 mm)。f' に対して F(第2倍音)−30.1、c −30.8、f −10.4、c' −21.0 セント。オクターブの幅は 3→6 が +9.8、4→8 が +10.4、6→12 が +11.1。
  • 形の注意。摂動は振幅 2.96 mm、中心はリムから 531 mm、周期 490 mm。リムから 450〜620 mm で径が最大 +11.7% 膨らむ。Bb の全長は 2782.3 mm(⌀12 の円筒を上流で 80.8 mm 縮める)。RefHorn は同じ条件で、F 管の延長量 944.1 mm。

入力インピーダンス |Z|

縦軸は対数(Pa·s/m)。ピークの位置が倍音の音程、高さが鳴りやすさの目安。

f' を基準にした音程差

Bb 管は第6倍音、F 管は第8倍音(どちらも f')のずれを 0 とし、各倍音のずれとの差を示す。f(f' のオクターブ下)が負ならオクターブが広く、正なら狭い。

倍音の音程(a' = Hz の平均律からのセント)

ピークとして認識できた倍音ごとに、Bb 管は Bb,、F 管は F, の倍音列に最も近い平均律の音からのずれ。音名はヘルムホルツ式(c' = 中央の c、c'' はその 1 オクターブ上)。第7・第11・第13・第14倍音などは、もともと平均律から外れる倍音。

管内の音圧分布(bell02)

calcspd で求めた、各倍音のピーク周波数での音圧レベル(入力端 0.02 Pa)。横軸はベル開口を 0 とした、芯線に沿った長さ。薄く塗った範囲は局所的な摂動を入れた区間、点線は bell02 の始まり(⌀12 の端)。
