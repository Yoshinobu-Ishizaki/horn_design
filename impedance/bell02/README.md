# ベルのメンズールを音程から合わせ込む計算(bell01・bell02)

ホルンのベル(リムから1番管の終わりまで)のメンズールを、入力インピーダンスのピーク(共鳴)の音程を目標にして決めた計算の記録。bell01 で手法を作り、bell02 で条件を変えて試算した。

## 1. 計算のモデル

### 1.1 管の構成

マウスピース側から次の順につなぎ、1本のメンズール(`.men`、直径と長さの区間の並び)にする。

| 部分 | 内容 |
|---|---|
| 上流 | kanutils のサンプル `refhornBb000.men` の x = 0〜1413 mm(マウスピース RefMP、吹込管、ロータリー・抜差管など。最後は ⌀12.0 の円筒) |
| ⌀12 の円筒の増減 | 上流の最後の円筒の長さを変える(`dcyl`)。Bb 管の全長を調整し、1番管の末端の直線にあたる |
| F 側の延長管(F 管だけ) | ⌀12.0 の円筒(長さ `Fx`)。F 側の実際の経路がないための近似 |
| ベル | リム ⌀300 から ⌀12 までのメンズール関数(1.3) |

RefHorn そのもの(サンプルのまま)も同じ条件で計算し、比べた。

### 1.2 右手補正と計算条件

- 右手: kanutils の `righthand`(挿入深さ 220 mm)。メンズールを反転(ベル側から)→ XY → 右手補正 → メンズール → 反転、の順に掛ける。
- 入力インピーダンス: `calcimp`(0〜1500 Hz、1 Hz 刻み、24 ℃、放射はフランジなし、管壁損失あり)。
- ピーク: `imppeak`(前後3点の多項式で近似)。ピークを低い順に第1、第2…倍音とする。

### 1.3 ベルのメンズール関数

`mensur/bell/make_bell.ipynb` の関数 a/(x+b)^p + c に、1次の項 q·x を足したもの。x はリムからの距離(芯線に沿った長さ、mm)。

D(x) = a / (x + b)^p + c + q·x

- 条件: D(0) = 300(リム)、D'(0) = 2·tan(ANG)(リムの開き角)、D(X_END) = 12(1番管の終わり)。
- a, c は D'(0) と D(0) から、b は D(X_END) = 12 から決まる。形を決めるのは p、ANG、Q と、⌀12 になる長さ X_END。
- D はリムから細い側へ単調に減ること(拘束)。

実装: `cad/bell01/tools/make_mensur.py`(`diameter()`)。

### 1.4 局所的な摂動

基本形に、ガウス窓を掛けた余弦を足す。

δD(x) = A·exp(−((x − L0)/w)²)·cos(2π(x − L0)/λ)、w = λ/4.3

- w = λ/4.3 なので、L0 ± λ/2 で窓は exp(−(4.3/2)²) ≈ 0.01 になり、摂動は約1波長の区間に収まる。その外は基本形のまま。
- 考え方(ユーザーの提案): 管内の音圧の高い所で径を広げると、その共鳴の周波数は下がり、音圧の低い所(粒子速度の高い所)では上がる。音圧分布(`calcspd`)を見ると、各共鳴の影響の重みは空間的に半波長の周期で変わる。そのため、摂動の周期 λ を動かしたくない共鳴の波長に合わせると、その共鳴への影響は腹と節で打ち消し合う。半波長に合わせた共鳴には、強め合って大きく効く。
- 拘束: D の単調減少を保つ。見た目のうねりを抑えるため、振幅に罰則 AMP_W·A² を掛ける。

### 1.5 音程の見方

- 音名はヘルムホルツ式(c' = 中央の c = C4、c = C3、C = C2、C, = C1。フラットは bb' のように b を付ける)。
- 各倍音のピーク周波数を、Bb 管なら Bb, 、F 管なら F, の倍音列に最も近い平均律の音(a' = 442 Hz)と比べたセント。
- f'(Bb 管の第6倍音、F 管の第8倍音)を基準にし、各倍音の f' との差を見る。
- オクターブの幅 = 上の倍音のずれ − 下の倍音のずれ(例: 3→6 は第6倍音 − 第3倍音)。正なら広く、負なら狭い。

## 2. 合わせ込みの方法

目標との差(セント)の二乗和(と形の罰則)を、Nelder–Mead 法で最小にする。1回の評価で、メンズールを作り、右手補正を掛けて calcimp と imppeak を実行する(Bb 管・F 管の2回で約2.5秒)。D が単調に減らない形は評価しない(大きな値を返す)。

Nelder–Mead は局所的な方法なので、1回で止まったところから、刻みを小さくしてやり直すと、さらに下がることがある(bell02 の第2段で有効だった)。

## 3. bell01 の経過

| 段階 | スクリプト | 変数 | 目標 | 結果 |
|---|---|---|---|---|
| 1 | `impedance/bell01/tune_mensur.py` | p, ANG, Q, X_END | Bb の第2・第3・第6倍音 | 目標には届くが、ほかの倍音の並びが崩れる場合があった |
| 2 | `impedance/bell01/tune_octaves.py` | p, ANG, Q, X_END, Fx | Bb・F の 3→6、4→8 = +10、Bb の f' = +16、F の f' = Bb + 10 | 4つのオクターブとも +9.6〜+10.6(基本形として採用) |
| 3 | `impedance/bell01/tune_perturb.py` | A, L0, (λ), dcyl | Bb の bb − f' = 0 ほか、基本形の値を保つ | λ = 730 mm(Bb の第4倍音の半波長)に固定して A = 0.158 mm。bb − f' が +4.5 → +1.9 で、f の低下との兼ね合いで止まった(採用) |
| 4 | `impedance/bell01/tune_f2bell.py` | 2つ目の摂動 | F の第2倍音 − f' = −30 | −54 までで、Bb 側がずれる(不採用)。F 延長管を ⌀11.8 にしても −56 |

bell01 の決定版: p = 2.1061、ANG = −70.733°、Q = −0.005524、X_END = 1304.93、摂動 A 0.158・L0 530.5・λ 730、⌀12 の直線 +1.69。レポートは `impedance/bell01/report.py`。

## 4. bell02 の試算

bell01 では F の第2倍音が f' に対して −62 と低かった。bell02 では、これを −30 にすることを最初から目標に入れ、さらにオクターブ 6→12 も加えた。

### 4.1 目標

- F の第2倍音 − f' = −30
- オクターブの幅 3→6、4→8、6→12 が Bb 管・F 管とも +10
- Bb の f' = +16、F の f' = Bb の f' + 10
- リム ⌀300 と細径 ⌀12 は変えない。X_END は最長 1500 mm 程度まで

### 4.2 第1段: 長さごとの基本形(`scan_length.py`)

X_END = 1200、1300、1400、1500 mm のそれぞれで、p、ANG、Q、dcyl、Fx を合わせ込んだ(摂動なし)。どの長さでも F の第2倍音は −28〜−37 まで上がったが、オクターブの幅はそろわなかった。

| X_END | 誤差 | Bb 3→6 | Bb 4→8 | Bb 6→12 | F 3→6 | F 4→8 | F 6→12 | F の第2 |
|---|---|---|---|---|---|---|---|---|
| 1200 | 1215 | +17.6 | −11.2 | +29.0 | −4.5 | +17.7 | +6.2 | −36.7 |
| 1300 | 531 | +15.4 | −5.8 | +22.8 | +2.7 | +14.9 | +11.8 | −31.7 |
| 1400 | 444 | +6.0 | −5.3 | +20.5 | +17.9 | +7.1 | +11.4 | −27.6 |
| 1500 | 1529 | −13.2 | −4.7 | +19.1 | +29.4 | −6.6 | +10.5 | −29.5 |

### 4.3 第2段: 基本形と摂動1つ(`refine_perturb.py`)

変数は p、ANG、Q、A、L0、λ、dcyl、Fx の8つ。誤差の小さい 1300・1400 mm から始め、さらに 1400 mm の結果から、1350・1400・1450 mm で刻みを小さくしてやり直した。

| X_END | 誤差 | Bb 3→6 | Bb 4→8 | Bb 6→12 | F 3→6 | F 4→8 | F 6→12 | F の第2 | 摂動 A / L0 / λ |
|---|---|---|---|---|---|---|---|---|---|
| 1300 | 434 | +15.7 | −4.4 | +21.4 | +4.4 | +14.8 | +12.1 | −31.8 | 1.70 / 714 / 452 |
| 1350 | 111 | +12.6 | +3.7 | +10.2 | +6.5 | +12.5 | +16.3 | −31.9 | 2.10 / 454 / 429 |
| 1400 | 23 | +10.6 | +7.6 | +9.5 | +8.9 | +10.9 | +13.5 | −30.4 | 2.84 / 494 / 368 |
| **1450** | **4.6** | **+9.9** | **+9.2** | **+9.9** | **+9.8** | **+10.4** | **+11.1** | **−30.1** | **2.96 / 531 / 490** |

### 4.4 結果(X_END = 1450)

条件をすべて ±1.1 セント以内で満たす形が見つかった(`refine_x1450r.json`)。

- 基本形: p = 2.6330、ANG = −65.313°、Q = −0.008170、X_END = 1450
- 摂動: A = 2.96 mm、L0 = 531.1、λ = 489.9(リムから 286〜776 mm)
- dcyl = −80.8 mm(Bb の全長 2782.2 mm)、F の延長管 939.3 mm
- Bb の f' = +15.9、F の f' = +25.9

| f' との差(セント) | 2 | 3 | 4 | 6 | 8 | 10 | 12 |
|---|---|---|---|---|---|---|---|
| Bb 管(f' = 第6) | −20.9 | −9.9 | −13.6 | 0 | −4.4 | −32.7 | +9.9 |
| F 管(f' = 第8) | −30.1 | −30.7 | −10.4 | −21.0 | 0 | −7.3 | −9.9 |

### 4.5 注意点

- **見た目**: 摂動の振幅が 2.96 mm と大きい(bell01 は 0.158 mm)。リムから 450〜620 mm で径が最大 +11.7% 膨らみ(L = 531 で ⌀25.3 → ⌀28.2)、径の傾きがほぼ水平(−0.006)まで寝る。単調減少は保っているが、膨らみとして見える可能性が高い。
- **並び**: 目標はオクターブの幅だけなので、f' との差は bell01 と違う。Bb の bb が f' より −13.6、bb' が −4.4、F の c が −30.7、c' が −21.0 と、f' 以外が全体に低い。
- **F 管**: F 側の実際の経路はなく、⌀12 の円筒で近似している。
- **方法の限界**: Nelder–Mead の局所解。長さ 1450 で十分に合ったが、ほかの長さや開始点にもっと良い(振幅の小さい)解がある可能性はある。

## 5. 再現の手順

```
# bell01
uv run python cad/bell01/tools/make_mensur.py        # メンズールの表
uv run python impedance/bell01/intonation.py         # 音程(F 管の延長量も決める)
uv run python impedance/bell01/report.py             # レポート(report.html)

# bell02(第1段は長さごと、第2段は第1段の結果から)
uv run python impedance/bell02/scan_length.py 1400
uv run python impedance/bell02/refine_perturb.py 1400
uv run python impedance/bell02/refine_perturb.py 1450 impedance/bell02/refine_x1400.json
```

calcimp などは `~/develop/kanutils/src/` の実行ファイルを使う。1回の合わせ込みは数分〜40分(4つまで並列に実行した)。
