# bell03 のメンズールの作り方

bell03 は、2026-11-23 に採用したベル(ベル + 1番管)。入力インピーダンスのピーク(共鳴)の音程を目標にして、メンズール関数と局所的な摂動1つを合わせ込んで作った。計算のモデル(管の構成、右手補正、calcimp の条件、メンズール関数、摂動の形、音程の見方)は bell01・bell02 と同じで、[impedance/bell02/README.md](../bell02/README.md) の 1 章に書いた。ここでは bell03 で変えたことと、探索の経過、採用した値を書く。

## 1. bell02 から変えたこと

bell02 は目標をすべて ±1.1 セントで満たしたが、次の点が好ましくなかった。

- 摂動の振幅が 2.96 mm と大きく、リムから 450〜620 mm で径が最大 +11.7% 膨らむ(見た目のうねり)。
- フレア(リムから 150 mm 以内)が bell01 より太い(リムから 100 mm で ⌀103.2、bell01 は ⌀85.6)。
- Bb 管の bb'(第8倍音)の f' との差が −4.4 と負。
- F 管の c'(第6倍音)の f' との差が −21.0 と低い。

そこで bell03 では、bell02 の目標に次の拘束を足した。

| 追加した拘束 | 目的関数での扱い |
|---|---|
| 摂動の振幅を小さく | 3.0·A²(bell02 の 10 倍) |
| Bb 管の bb' − f' ≥ 0 | bb' − f' が +1 を下回った分に 4·(不足)² |
| フレア(リムから 150 mm 以内)を bell01 より太くしない | bell01 の径の 1.02 倍を超えた分 (mm) の最大値に 10·(超過)² |
| F 管の c' − f' = 0 | 目標の1つとして(重みはほかと同じ) |

bell02 から引き継いだ目標(セント、a' = 442 Hz):

- F 管の第2倍音 − f'(第8倍音)= −30
- オクターブの幅(上の倍音のずれ − 下の倍音のずれ)3→6、4→8、6→12 が Bb 管・F 管とも +10
- Bb 管の f'(第6倍音)= +16、F 管の f' = Bb 管の f' + 10

固定したもの: リム ⌀300、細径 ⌀12、⌀12 になる長さ X_END(開始点ごとに固定)。

## 2. 探索の方法(`search.py`)

変数は8つ: メンズール関数の p、ANG(リムの開き角)、Q(1次の項)、摂動の A(振幅)、L0(中心、リムから)、λ(周期、窓の幅は w = λ/4.3)、dcyl(上流の ⌀12 の円筒の増減。Bb 管の全長を調整)、Fx(F 管の延長管の長さ)。

目的関数は、目標との差(セント)の二乗和に、1 章の罰則を足したもの。Nelder–Mead 法で、開始点ごとに 700 回まで回し、止まったところから刻みを 1/3 にしてもう一度回した。1 回の評価は Bb 管・F 管の calcimp で約 2.5 秒、開始点を 4 つ並列に実行した(各 1 時間強)。

| 開始点 | X_END | 初期値 |
|---|---|---|
| a | 1450 | bell02 の解(振幅を 0.4 倍に) |
| b | 1400 | bell02 の 1400 mm の解(振幅を 0.4 倍に) |
| c | 1450 | bell01 の基本形(p 2.1061、ANG −70.733、Q −0.005524)、A 0.5 |
| d | 1350 | 同上 |
| e | 1450 | a と同じで、フレアの拘束だけを外す(切り分け用) |

a はフレアが bell01 より 18 mm 以上太いところから始まり、進まなかったので途中で止め、e に替えた。

## 3. 結果

条件をすべて満たす形は見つからなかった。

| 開始点 | 誤差 | Bb 3→6 | Bb 4→8 | Bb 6→12 | F 3→6 | F 4→8 | F 6→12 | F の第2 | F の c' | Bb の bb' | フレアの超過 | 振幅 A |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| b | 820 | +5.7 | +8.2 | +25.3 | +12.6 | +7.5 | +19.2 | −33.9 | −11.0 | +9.3 | 5.3 mm | 1.69 |
| **c** | **552** | **+12.3** | **+10.2** | **+25.2** | **+9.4** | **+11.8** | **+12.9** | **−33.8** | **−2.2** | **+0.4** | **5.1 mm** | **1.82** |
| d | 536 | +13.9 | +0.9 | +22.4 | +7.3 | +12.9 | +18.1 | −33.6 | −2.5 | +3.8 | 4.1 mm | 1.74 |
| e | 333 | +4.1 | +5.3 | +10.6 | +14.5 | +6.0 | +11.4 | −30.4 | −14.7 | +0.9 | 17.8 mm | 2.22 |

(e の誤差は、フレアの超過を罰則に入れていない値。)

分かったこと:

1. フレアを bell01 程度に抑えると、Bb 管の 6→12 が +22〜25 に広がる(b・c・d のどれでも)。F の第2倍音 −30 と 6→12 +10 を両立させるには、bell02 のようにフレアを太くする必要があるらしい。
2. F 管の c' を f' に近づける条件は、フレアの拘束を外しても満たしにくい(e で c' は −14.7、F の 3→6 は +14.5)。

最もバランスの良い c を bell03 として採用した。外れているのは Bb 管の 6→12(+25.2)と、フレアが bell01 の +2% を最大 5.1 mm 超えることの 2 点。

## 5. CAD への反映(`cad/bell03/`)

- 芯線は bell01 と同じ考え方: リムから直線 250 mm、そこから ⌀275 の円板に巻き付く渦巻き(管の内側が円板に接する)。ベルは 840.635 mm で終わる。
- 1番管(609.365 mm): ベルの渦巻きを延ばし、内側の円の半径を BRANCH_DRI·s² で減らして内側へ曲げる。渦巻きは 1番管の中の 312.4 mm でやめ、R50 の円弧(110.8°)で、組立の基本姿勢(リム中心まわりに Z 軸で +15°)で +X を向く直線(200.3 mm)につなぐ。直線の高さは組立姿勢で円板の中心より 10 mm 上(暫定)。末端は組立姿勢で (216.6, 303.9)。
- 渦巻きをやめる点は、1番管の中の 150 mm 以降から探す(BRANCH_EXIT_MIN。手前の解は直線がベルを横切る)。
- 1番管とベルの外面どうしの最近接距離(板厚 0.4 mm): **1.4 mm**(BRANCH_DRI = 57.28)。板厚を付けたソリッドどうしの 3D 距離で 1.4019 mm。最近接はベルの直管部の横、設計の座標で (24.7, 236.1) 付近。
- 板厚は外向き 0.4 mm(`vss.variable_pipe_wall(method="sweep")`)。

## 6. 再現の手順

```
uv run python impedance/bell03/search.py c 1450 bell01          # 探索(1 時間強)。結果は result_c.json
uv run python cad/bell03/tools/make_mensur.py                   # メンズールの表(bell03-ld.csv)
uv run python impedance/bell03/intonation.py                    # 音程(RefHorn と比較)
uv run python impedance/bell03/report.py                        # レポート(report.html)
uv run python cad/bell03/ocp/bell03_surface.py --wall 0.4 --show   # CAD をビューアに
uv run python cad/bell03/tools/compare.py bell03 bell01         # bell01・RefBell と重ねて表示
```
