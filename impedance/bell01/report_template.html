bell01 の音程チェック

bell01(1番管 + ベル)を付けたホルンの入力インピーダンスを calcimp で計算し、RefHorn と同じ条件で比べた。右手補正あり。

要点

  • Bb 管は f' を基準に目標どおり。f'(第6倍音)が a' = 442 Hz で +16.0 セント、Bb(第2倍音)が f' より −20.0、f(第3倍音)が −10.0 セント。メンズールの p・開き角・q と ⌀12 になる L を合わせ込んだ(前の形からの変化は直径の二乗平均で 0.76 mm、全長は 2746.5 mm)。
  • F 管の f(第4倍音)は f' より −10.6 セント。RefHorn は +9.5 で、オクターブが狭い。c(第3倍音)は f' より −21.0。
  • f' より上は、f' との差が RefHorn より小さい。Bb 管の bb'(第8倍音)は f' より +5.5(RefHorn は +15.8)、F 管の a'(第10倍音)は −9.7(RefHorn は −0.6)セント。
  • F 管の延長量は 939.3 mm。F 管の f' を Bb 管の f' より 10 セント高くする条件で決めた(F 管の f' は +26.0)。RefHorn も同じ条件で 944.1 mm。F 側の実際の経路はなく、⌀12 の円筒を足した近似。

入力インピーダンス |Z|

縦軸は対数(Pa·s/m)。ピークの位置が倍音の音程、高さが鳴りやすさの目安。

f' を基準にした音程差

Bb 管は第6倍音、F 管は第8倍音(どちらも f')のずれを 0 とし、各倍音のずれとの差を示す。f(f' のオクターブ下)が負ならオクターブが広く、正なら狭い。

倍音の音程(a' = Hz の平均律からのセント)

ピークとして認識できた倍音ごとに、Bb 管は Bb,、F 管は F, の倍音列に最も近い平均律の音からのずれ。音名はヘルムホルツ式(c' = 中央の c、c'' はその 1 オクターブ上)。第7・第11・第13・第14倍音などは、もともと平均律から外れる倍音。
