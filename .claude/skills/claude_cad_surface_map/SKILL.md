# claude_cad_surface_map

曲面に輪郭をマップし、曲面上の面(コピー)に厚みを付けて座を作るスキル。共通の決まり(uv、build123d、git、worklog、OCP Viewer と計測用バックエンド、値を推測しない、数値で確かめる、文字化け対策)は `claude_cad_general` に従う。実装は `src/bope_claude_cad/surface_map.py`、テストは `tests/test_surface_map.py`。

## 基本方針

1. 流れは「輪郭を用意 → マップ → 厚み付け → 検査」。曲面上の面は、元の面のコピーとして作る(元の面は変えない)。
2. **マップは2通り。ユーザーに、どちらかを必ず確かめる**(言われていなければ推測しない)。
   - `wrap`: ブランク(XY 平面の平らな板)を、基準点の法線に垂直に置き、縦横の長さが保たれるように曲面へ貼る。展開した板から曲げる部品向き。
   - `normal`: 基準点の法線方向への平行投影。型で言う「投影面」。傾いた所で面積が増える。
3. **長さのずれは警告だけで止めない**(ユーザーの方針)。警告は結果と一緒に報告する。

## 入力

- 輪郭: DXF(`outline_from_dxf`。LINE・ARC・CIRCLE・直線の LWPOLYLINE。最大の閉じた線が外周、ほかが穴。**図枠や別の図、寸法線が同じシートにあるときは、`window=(x0,y0,x1,y1)`・`solid_only=True`(想像線・破線を除く)・`types=("ARC",)` などで絞る**。**右端などが縦線に見えても円弧のことがある(R144.08 など)ので、DXF の図形を一覧して確かめる**。`center="left"` で、左端・縦の中央(左の頂点)を基準点にする)、言葉の指定(build123d の `Rectangle` `SlotOverall` `Circle` などを XY 平面に)、STEP の平面(`outline_from_face`)。
  - どれも、**輪郭の原点(既定は外形の中心)が基準点に載る**。基準点を重心以外にしたいときは `center=False` にして、原点を意図の位置に置く。
  - DXF のバルジ(円弧)つき LWPOLYLINE は未対応。ARC に分解してもらう。
- 基準点 `point`: 曲面上か近く(最近点に寄せる)。座標は、面と同じ座標系。
- 基準方向 `x_dir`: ブランクの「横」方向。接平面へ射影して使う。**ブランクの縦横が曲面のどちらに向くかは、これで決まる。ユーザーに確かめる**(例: 管軸方向)。
- 厚み `thickness`、向き `outward`(True は面の法線側)。**どちら側に付けるかは、基準点の法線で固定する**(面ごとに向きがばらついても同じ側になる)。

## 手順

1. 曲面の Face を用意する(STEP から読むなら `claude_cad_general` の調査手順)。Viewer に出して、基準点の位置をユーザーと合わせる。
2. 輪郭と `SeatParams(point, x_dir, thickness, mode, outward)` を決める。
3. `solid, report = make_seat(surface, outline, params)`(個別には `map_outline` → `thicken_seat` → `check_mapping`)。
   - `normal` で曲面の継ぎ目をまたぐと、面が複数枚になり、ソリッドは list で返る。
4. `report["warnings"]` をユーザーに見せる。`edge_ratios` は、元の外周の各辺に対する、マップ後の長さの比。
5. Viewer に表示する(`names=` で部品名を付ける。曲面は薄く、座は色を変える)。
6. 確定したら STEP に出す。履歴・コミットは `claude_cad_general` に従う。

## 規則と実測(build123d 0.13.0)

- **`wrap` は 3 つの方法がある**(`SeatParams.wrap_method`)。ブランクには、たいてい縦横の長さ方向(長手 x と幅 y。例: 59.79 と 54)がある。**面に貼ったとき、周の長さでなく、この縦横の長さが元と変わらないことを優先する(既定は `section`)**。
  - `"section"`(既定): 基準点 A から x 方向に、**曲面を、法線と x 方向を含む平面で切った線(子午線)**を取り、その上に弧長 x の点 S(x) を置く。S(x) で、**子午線の接線に直交する平面(接平面ベクトルと法線で張る)で曲面を切った断面線**に沿って、弧長 y の点を取る(+y は 法線 × 子午線の接線)。輪郭の各点をこの写像で写し、辺ごとにスプラインで結ぶ。**長手は子午線に沿って、幅は各断面線に沿って、元の長さと一致する。** 閉じ目の隙間は出ない。周の長さは保たない(辺の比は参考値で、警告しない)。曲面を切る回数が多く、RefBell のベル(局所の面)で約 20 秒。ほぼ同じ x の断面は共有する(上下対称の輪郭で半分)。`make_seat` が、面から独立に子午線上 7 か所の断面の幅を測り(`report["widths"]`、`width_worst`)、ずれると警告する。
    - 実測: RefBell ベルで、幅のずれ 0.0007 mm 以内(同じ輪郭を `march` で貼ると、幅が最大 3.4 mm ずれる)。芯線上の位置は L 128.003〜186.887(図面の 128.0〜186.85)。円筒・自由曲面・球でも、幅のずれは 0.05 mm 以内(テスト)。
    - 輪郭の標本間隔 `step`(既定 1.0 mm)ごとに断面を切る。小さいと遅い。
    - **長手(子午線に沿う方向)の選び方**(`SeatParams.long_axis`、既定 `"auto"`): ブランクの縦横で**長い方**。差が 15% 未満なら、**貼られる面の法曲率(`normal_curvature`、オイラーの式)が小さい方**。`"length"` `"curvature"` で片方の基準だけにでき、`"x"` `"y"` で指定できる。y を長手にするときは、ブランクを -90° 回し、座標系の x を 法線 × x_dir に取り直して、同じ処理にする(結果は `params.extra["long_axis"]`)。長手と幅の検証も、同じ向きで行う。
    - **単純曲面(平面・円筒・円錐)の専用ルートは不要**: build123d には展開(unroll・develop)の関数がなく、使えるのは汎用の `Face.wrap` だけ。実測(円筒 R20、円錐、40×16 の長方形): `section` は円筒 0.8 秒・円錐 0.9 秒で、面積比 1.0000、幅のずれ 0.0004 mm。`Face.wrap` は、円筒 0.8 秒で面積比 1.0045・幅 0.023 mm ずれ、円錐は 24 秒かかって壊れた(面積比 0.008)。解析面は OCC の交線計算が速いので、`section` が速く厳密。遅くなるのは B スプライン面(ベルなど)のときで、そのときは局所の面を使う。
  - `"march"`(自前。周の長さを保ちたいとき): 輪郭を 0.5 mm 刻みの点列にして、基準点から曲面上を一歩ずつ進める(各ステップは接平面内で元の長さだけ進めて曲面へ射影し、基準方向は接平面へ射影して引き継ぐ)。**速く(数秒)、失敗しない。** 一周して戻った隙間は周に一様に配り、大きさを警告する。面は、輪郭と曲面上の格子点(`fill_grid`、4 mm)を通るように張る(曲面からの浮きは 0.001 mm)。
  - `"build123d"`(`Face.wrap`): 許容誤差(`tolerance`、0.05 mm から 2 倍ずつ緩める)と継ぎ目の辺をずらして再試行する。**巨大な B スプライン面では 1 回に 2 分、ほぼ円錐の面では閉じ処理で OCC のエラーになり得る**(RefBell のベルで、継ぎ目を 8 通り試しても全滅)。比較用。
- **周の長さを保つ貼り付け(`march`)は、負の曲率の面(フレア、鞍形)では閉じ目が閉じない**(`section` は周を保たないので出ない)(ガウス曲率 K と囲む面積 A で、保持角 ≈ K·A)。これは原理で、バグではない。隙間 = 保持角 × 半径。実測:
  - 円筒: 隙間 0、辺のずれ 0。
  - RefBell ベルの外面(フレア)に 59.8×54 の座: 隙間 3.4 mm、辺のずれ ±1.7%、面積比 0.989(概算 K·A·r でも 2.4 mm で、桁が合う)。
  - 輪郭が大きいほど、曲面の曲がりが強いほど増える。大きいときは、輪郭を分割するか `normal` を提案する。
- **面の曲面からの浮きの測定**: `Face.position_at(u, v)` は、輪郭の外(面の定義域のはみ出し)の点も返す。**面の上にある点(`distance_to` が 0)だけ**を使う。使わないと、浮きを 0.14〜0.19 mm と誤測する(実際は 0.001)。
- **曲面へ投影し直して厳密な面にする方法(`reproject=True`)は実験的**。閉じた管では手前の壁と反対側の壁の両方が返り、手前の壁も継ぎ目で複数枚に分かれる。結果が不安定なので既定では使わない。
- 継ぎ目で面が複数枚に分かれたら(`normal` など)、厚み付けのあとで 1 つのソリッドに融合する(できなければ list のまま、警告)。
- **局所の面を使うと速い**: 貼る面がモデル全体の巨大な面だと、最近点の計算が遅い。座の周りだけの面(例: 芯線の直線部 L 100〜220 だけの可変断面スイープ。法則は全体のスプラインを標本化)を作って渡す。`jigs/refbell_seat/build_seat.py` の `build_surface(local=...)`。
- `normal` の `project_to_shape` は、投影方向の前後(表と裏)の面を返す。表側(法線が基準法線と同じ向き)で、基準点に近い面だけを残す。
- 厚み付けは `Solid.thicken`。曲率半径が厚みより小さい凹側では自己交差する。**検出は未実装**。凹側へ厚みを付けるときは、`is_valid` と体積を見る。
- 面が足りない(輪郭が曲面の縁をはみ出す)と、`wrap` は不正な面になるか失敗する。`normal` は縁で切れた面になる。面積比の警告で気づく。

## 実績

- RefBell 支柱座(1) E0102(`jigs/refbell_seat/`)。図面 YRefBellD の展開図を、claude_cad_vss のベルの外面(ボア + 板厚 0.4)にマップ。位置は、図面の直径列を L-D 表のボア直径 + 0.8 に最小二乗で当てはめて決めた(L0 = 186.848、残差 RMS 0.005 mm)。**図面の直径が、ボアでなく板厚を足した外径か、当てはめで確かめる**(+0 では RMS 0.19、+0.4 では 0.09 で、+0.8 だけが合った)。

## 未実装・今後

- 厚み付けの自己交差の検出。
- `section` の長手方向は、輪郭の x 方向の 1 本の子午線に限る。輪郭が長手に対して大きく曲がった形(L 字、円弧状)や、
  x の同じ位置で輪郭が複数の区間に分かれる形は、幅を断面ごとに単一の線と見なすので、貼り方を確かめる(幅の検証は区間の合計)。
- `section` の長手は自動で選ぶが(上の `long_axis`)、結果(`params.extra["long_axis"]`)をユーザーに伝える。長手が x_dir 方向でなくても、`x_dir` は「ブランクの +x が曲面のどちらを向くか」を表す。
- 中心投影(`Wire.project_to_shape(center=...)`)。
- 座を貼る側(芯線の平面の左右、円周方向の位置)は図面に指定がなく、仮に決めてある。
