# claude_cad_vss

芯線と、芯線に沿った直径の表から、直径が連続的に変わる管を作るスキル。実績: RefBell ベル(`sample/`)。共通の決まりと道具は `claude_cad_general` に従う(uv、build123d、git、worklog、OCP Viewer と計測用バックエンドの起動、値を推測しない、数値で確かめる、文字化け対策)。このスキルは、可変断面スイープに固有のことだけを書く。

## 基本方針(最重要)

1. **依頼されたら、基本はサーフェス(端面のない側面だけのシェル)で作る。** ソリッドは、頼まれたときだけ。
2. **ソリッドにするときは、そのサーフェスを、面の法線方向にオフセットして板厚を付ける。** 直径に板厚の2倍を足した別のスイープを作らない(法線方向の厚みにならない)。端面は、面の法線方向で切る(芯線に垂直な平面で切らない)。リムのように面が大きく傾いた所では、この差が効く。

## 入力と規則

- 芯線: 始点が L=0 のワイヤ(平面でも3次元でもよい)。接線が連続な曲線(円弧・直線・スプライン)をつなぐ。
- L-D 表: L(芯線に沿った距離)と D(直径)の組。関数形 D = f(x) でもよい(下の規則)。
- **表の L を3次スプライン(not-a-knot)で当てはめ**、任意の L の直径を内挿する。表が粗くても滑らかになる。法則関数の節点は表の L そのもので、スプラインと一致する。
- **表が芯線より長い**: 芯線の終点で切る。終点の直径は、スプラインで内挿する。
- **表が芯線より短い**: 表の最後の L で終える(外挿しない)。
- **表が L=0 より後から始まる**: 表の最初の L から始める。
- **法則が D = f(x) の関数形で与えられたとき**(例: `D = 40 - 0.05x`、`D = 20 + 30·exp(-x/200)`): **x = L(芯線に沿った距離、mm)と解釈する。** `table_from_function(f, 0, 芯線の長さ)` で L-D 表にして、以降は表と同じに扱う(`f` は Python の関数でも、式の文字列 `"D = 40 - 0.05*x"` でもよい。べき乗は `**` か `^`)。
  - 定義域が示されていれば、その範囲を `l_min`〜`l_max` に渡す(示されていなければ 0〜芯線の長さ。芯線より長い・短いときの扱いは上の規則と同じ)。
  - 関数が D ≤ 0 や非有限になる L があると ValueError(定義域か式の読み違いを疑う)。
  - 式の x が L でなく別の変数(半径 r、角度など)だったら、推測せずユーザーに確かめる。
  - 内挿は 5 mm 間隔(既定 `step`)の3次スプライン。急に曲がる関数は `step` を小さくする。
- 芯線の長さと表の終端が(ほぼ)一致するはずの図面では、**一致を確認する**。ずれていたら、芯線の起点か寸法の読み違いを疑う(ベルでは、起点を 0.5 mm 読み違え、全長が 850.67 になっていた。正しくは 851.163 で、表の終端と一致した)。
- 曲率半径が、その位置の半径(D/2)より小さいと、自己交差する。検出は実装していない。

## 手順

1. 入力を用意する。`.cad`(CADRA)は `cadra-converter` スキルで DXF にする。DXF から芯線と表を取る例は `scripts/bell_from_dxf.py`(**ベル専用**。円弧の順序、表の列の位置、起点は、案件ごとに読み直す)。
2. 法則が関数形なら、`L, D = table_from_function(f, 0, centerline.length)` で表にする。
   芯線の長さと表の範囲を確認し、ユーザーに見せる(上の「入力と規則」)。
3. サーフェスを作る: `from bope_claude_cad.vss import variable_pipe_law`。`shell, prof = variable_pipe_law(centerline, L, D)`(`solid=True` でソリッド)。
4. 板厚を付けるときだけ: `wall, prof = variable_pipe_wall(centerline, L, D, 0.4)`(`outward=False` で内向き)。
5. 数値で確かめる: `check_variable_pipe`(ソリッドを渡す)で、中間位置の直径誤差と体積比。サーフェスは、面積を理想値(∫2πr√(1+r'²)dL)と比べる。ベルでは、直径誤差 0.0004 mm、面積比 1.00000。
6. Viewer に表示する(`scripts/show_bell.py`。`--wall 0.4` で板厚つき)。
7. STEP に出す(`scripts/export_bell_step.py`)。結果をコミットする。

## 実装(`src/bope_claude_cad/vss.py`)

| 関数 | 内容 |
|---|---|
| `table_from_function` | D = f(x)(x = L)の関数または式の文字列を、L-D 表に変換する |
| `fit_profile` | L-D 表を3次スプラインにし、終点 `l_end` を決める |
| `variable_pipe_law` | **本線。** OCC の `MakePipeShell` に法則関数(L → D/D0 の B-スプライン)を渡して掃引。断面は始点の円1つ |
| `variable_pipe_wall` | 内径面を `MakeOffsetShape` で法線方向にオフセットし、両端は内外の縁を結ぶ面(`BRepFill.Face_s`)で閉じてソリッドにする |
| `variable_pipe` | 比較用。芯線に垂直な円断面を多数置いて `make_loft`。誤差が大きい(ds=3 で 0.4 mm)ので、本線にしない |
| `check_variable_pipe` | 中間位置の直径誤差と体積比 |

### 落とし穴(実際に踏んだもの)

- **法則関数の定義域は、掃引する芯線の全長に割り当てられる。** 表が短い・途中から始まるときは、芯線を `[表の最初の L, 終点]` に切り詰めてから掃引する(実装済み)。しないと、形が引き伸ばされる(表と芯線の長さが一致するときだけ、偶然正しい)。
- 副法線の既定は `binormal=None`(補正フレネル)。方向を固定すると、芯線が1つの平面にないときに破綻する(体積比 0.60)。断面は円なので、ねじれは形に影響しない。
- 法則関数の節点は、**表の L にする**(600点などに再サンプルすると、リム付近で 0.04 mm の誤差が出た)。
- 板厚付けに、`thicken` を面ごとにかけて融合する方法、閉じたソリッドの両端を開口にした `offset`(MakeThickSolid)は使わない。前者は融合が壊れてソリッドが割れ、後者は端が平面で切れる。シェルへの build123d の `offset` は未対応なので、OCP の `BRepOffsetAPI_MakeOffsetShape` を直接使う。
- **体積の数値積分は、OffsetSurface を含む形で不安定**(約6%ずれた)。体積を報告するときは、B-スプライン面に変換した形(下の「STEP 出力」)で測る。厚みは、内面から外面までの距離(全点で 0.400 mm)で確かめる。
- 芯線の円弧の端点は、DXF では 1e-3 mm ずれていることがある。前の要素の終点に、次の円弧の始点を合わせてから `Wire` にする。
- 渦巻き状の芯線では、芯線に垂直な平面が別の枝も切る。断面の検査では、芯線上の点に最も近い面だけを使う(実装済み)。
- つなぎ目で、面の法線が最大 0.24° 食い違うことがある。**近似ではなく幾何学的なもの**で、芯線の曲率が飛ぶ所(直線→円弧、円弧→別の半径の円弧)で、半径が変化していると、法線が約 r'·Δκ·r だけ飛ぶ(許容値を絞っても変わらない)。接線は連続。必要なら芯線の曲率を滑らかにする。

## STEP 出力

- `MakeOffsetShape` の外面は、STEP で OFFSET_SURFACE になり、他の CAD で扱いにくく、体積も不安定になる。`BRepBuilderAPI_NurbsConvert` で B-スプライン面に変換して出す(ずれは 1e-5 mm 以下。ファイルは約 1.3 MB)。
- ベルの実績: 板厚 0.4 mm のソリッド 14 面、内径面のサーフェス 6 面(約 0.3 MB)。Creo で開くと、細い側がやや角ばって見えたが、図面に投影した外形線は滑らかだった(**Creo の表示メッシュの粗さ**。STEP は問題なし)。
- 出力先は `output/`(git 管理外)。サンプルは `sample/step/` に置く。

## Viewer での見せ方

真鍮・金管の光沢は、Studio タブ、色 `#cf9f30`、`metalness=1.0`、`roughness=0.02`、環境 `HIGH_CONTRAST_STUDIO`、トーンマッピング NEUTRAL、露出 0.8、背景はグラデーションの暗色(`scripts/show_bell.py`)。環境の写真を背景に出すと、合成のように見えて不採用。これ以上の写実さ(物体同士の映り込み)は、Viewer の描画方式では限界がある。

- 切り替え: `uv run python -m bope_claude_cad.viewer hide <部品名>` / `all`。ツリーの目のマークでも切り替えられる。線だけの部品(芯線)は、面のアイコンが無効で、エッジのアイコンで切り替える。
- Studio への切り替えには数秒かかる。スクリーンショットで確かめるときは、7〜10 秒待つ。
