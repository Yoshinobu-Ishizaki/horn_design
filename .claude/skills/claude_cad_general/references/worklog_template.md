# 作業記録 (<案件名>)

作業時間と指示の記録。時刻は JST。開始時刻は epoch <date +%s の値> (`date +%s`)。
指示ごとに、番号・指示(ユーザーの言葉を要約)・備考(決めた解釈、数値、確認の結果)を1行で追記する。
このファイルは、最後の設計手順書(備考の「かかった時間とやり取り」)の元データになる。

## 指示ログ

| # | 指示 | 備考 |
|---|------|------|
| 1 | <最初の指示。対象の STEP、作業場所、製法、出力> | 作業開始。作業フォルダ、製法(3D プリント / 組立)、出力形式と出力先を確認 |
| 2 | ... | ... |

## 経過

- 開始 epoch <値> / <節目> epoch <値> (<経過> 分)
- 形状: <製品の形、受ける面の名前と種類>
- 未決: <残っている確認事項>
- 注意: <古くなった出力、次の作業で更新するもの>

## 集計(手順書の備考に使う)

- 作業時間: 最後の epoch - 開始 epoch (`date +%s`)。指示や確認の待ち時間を含む
- 指示の件数: 指示ログの行数
- 確認の質問(AskUserQuestion)の回数
- コミットの数: `git log --oneline <開始前のコミット>..HEAD | wc -l`
- 作り直し(取り消し、やり直し)の回数と内容
