# 面・辺を指し示す(旧 claude_cad_pick_parts)

OCP CAD Viewer に表示した build123d のソリッドか STEP を対象に、「どの面・どの辺か」をユーザーと言葉で確実に共有する手順。`claude_cad_general` に取り込んだ。スクリプトは `../scripts/` の `pick_id.py` と `numbered_view.py`(`bope_claude_cad` の中では `uv run python -m bope_claude_cad.pick_id` などで呼ぶ)。

ビューアーで見ているモデルの、特定の面・辺を、ユーザーが「ここ」と指し示せるようにする。ユーザーがクリックして選んだ位置は、こちらからは読めない(選択はビューアーの中だけにあり、取り出す方法が無い)。ただし、ビューアーは面・辺に ID を持っており、ユーザーが ID を言葉で伝えれば、こちらでその面・辺を特定できる(次節)。色替えや独自の番号振りは要らない。

## ビューアーの ID で話す(基本)

- ビューアーのツリーとホバーのパスに、面・辺の ID が `<部品名>/faces/faces_12`、`<部品名>/edges/edges_5` の形で出る。ユーザーは「rod の faces_12」のように伝える。
- 数字は、その部品の `shape.faces()` / `shape.edges()` の並びの 0 始まりの添字(`ocp_vscode` の `select_faces(shape, [12])` と同じ。簡単な形で一致を確かめた)。
- ID を受けたら、まず `pick_id` で中身を引き、種類・大きさ・中心・向き・範囲を言葉で確かめる。

**基本: 部品名と ID だけで引く**(`bope_claude_cad.viewer.show` で表示した形。どのフォルダからでもよい):

```
uv run python -m bope_claude_cad.pick_id --part clamp_jaw faces 6 7
uv run python -m bope_claude_cad.pick_id --part clamp_jaw edges 12
uv run python -m bope_claude_cad.pick_id --list        # 最後に表示した部品の一覧(名前、面数、辺数、時刻)
```

- 作図スクリプトでは `ocp_vscode.show` の代わりに `from bope_claude_cad.viewer import show` を使う(引数は同じ)。表示のたびに、渡した形を `output/viewer_registry/<部品名>.brep` に記録する(`output/` は git 管理外)。ビューアーは `show` のたびに表示全体を置き換えるので、記録も毎回置き換わる。`jig_toolkit.show_parts` も、この記録に対応している。
- 記録は BREP で、面・辺の並びは保たれる(テストで確認)。ホバーの ID と同じ添字で引ける。部品名は `show(..., names=[...])` の名前。ホバーの `[部品名]` の名前を、そのまま使う。
- 名前なしで表示した形は `Part_<番号>` で記録する。ビューアーの名前と一致しないので、名前を付けて表示する。

**従来: 形を返すものを指定する**(`show` を使っていない形、STEP ファイルなど):

```
uv run python -m bope_claude_cad.pick_id <STEP ファイル | モジュール:関数> faces 12 30
uv run python -m bope_claude_cad.pick_id <STEP ファイル | モジュール:関数> edges 5
```

- 第1引数は、その ID の部品の形を返すもの(`numbered_view` と同じ。治具の作成スクリプトなら `PYTHONPATH=jigs/<治具名>`)。部品が複数あるときは、部品名を聞いてその部品の形で引く。ID は部品ごとに 0 から始まるので、部品名とセットで受ける。
- 引いた結果を「faces_12 は R10.3 の円筒面、中心 (x, y, z)、座の内側のことですか」のように返して確認してから、直す。
- ホバーで部品名や ID が出ないときは `ocp_hover_name.py` を当てる(`SKILL.md` の「ビューアーのホバーに部品名と面・辺の ID を出す」)。当てると、ステータス行が `[clamp_jaw faces_6] plane: area ≈ …` の形になり、「copy shape id」をしなくても ID が読める。
- 注意: 添字は形を作り直すと変わる。直した後は、ユーザーに ID を取り直してもらう。記録に残すときはコミットと組にする。ID は表示した形(`show` に渡した形)の添字なので、`show` の後に形を変えた別物では引かない。記録を使えば、表示した形そのものを引くので、この取り違えが起きない(記録が古いときは、`--list` の時刻と、直したあとの `show` の時刻を見比べる)。

## 番号を振って見せる(ID が使えないとき)

ビューアーを使えない、全体の面を一覧で見せたい、といったときは、下の方法で面と辺に番号を振って表示する。

## いつ使うか

- 「ここが違う」「この部分を直して」と言われたが、モデルのどこを指すのか分からないとき。
- 面や辺が多く、言葉で指すのが難しいとき(穴の内面、段、すみなど)。
- 修正のあとで、同じ面を番号で確かめ直したいとき。

指示の解釈が分かれる前に、まず番号を振って見せる。推測で直すより早い(事例: 台の座面の円筒が板との境目に食い込んでいたのを、ユーザーは「逃げがある」「円筒面が不要」と指摘した。円筒面の番号を見せていれば、一度で特定できた)。

## 使い方

前提: VS Code で OCP CAD Viewer を開いておく(既定のポートは 3939)。リポジトリ `bope_claude_cad` の中では、本体は `src/bope_claude_cad/numbered_view.py`。`scripts/numbered_view.py` はその写し(直したら両方をそろえる)。

```
uv run python -m bope_claude_cad.numbered_view <STEP ファイル | モジュール:関数> [faces|edges] [しきい値]
```

- 第1引数: STEP ファイルのパス。または `モジュール:関数`(形を返す関数。カレントとその下から import する。治具の作成スクリプトなら `PYTHONPATH=jigs/<治具名>` を付ける)。
- `faces`(既定): 各面を別の色の部品 `F<番号>` で出し、面の中心の外側に番号を置く。しきい値は小さい面の面積(既定 5 mm2)。
- `edges`: 形を半透明の `body` にして、各辺を別の色の部品 `E<番号>` で出す。しきい値は小さい辺の長さ(既定 3 mm)。
- 小さい面・辺(刻印の文字など)は、番号を振らず灰色の `small` にまとめる。しきい値の上げ下げで番号を減らす・増やせる。
- 標準出力に、番号・種類・大きさ(面積または長さ)・中心・法線(辺は向き)の表が出る。ユーザーに表(または要点)を見せ、番号で指してもらう。
- 視点は戻さない(`Camera.KEEP`)。
- 台の例(`jigs/brace_spot_lowbrass`): `uv run python jigs/brace_spot_lowbrass/tools/show_faces.py cb621_p9 [faces|edges]`。

ツリーには `F1`、`F2`…と部品が並ぶので、ユーザーはツリーでも番号を確かめ、表示・非表示を切り替えられる。

## 画面の確認

- 撮影: `from ocp_vscode import save_screenshot; save_screenshot("<png のパス>")`。撮った PNG を Read で読むと、ユーザーが見ている画面(視点を含む)を私も見られる。番号が読めるかの確認と、「この角度から見て」と言われたときに使う。ファイルはスクラッチパッドに置く。
- 状態: `from ocp_vscode import status; status()` が、視点(position、quaternion、target)と、部品ごとの表示・非表示(`states`)を返す。
- 選択はできない: クリックで選んだ面は読めない。ユーザーの答えは「面 12」のような番号、または画面に印をつけた画像。
- 計測(距離ツール、Properties ツール)は、計測用バックエンドが動いていないと使えない。ビューアーを使い始めるときに一緒に起動してあるはず(`SKILL.md` の「計測用バックエンドの起動」)。動いていなければ起動してから表示し直す。Properties ツールで面を選ぶと、面の種類・面積・中心・法線がビューアーに出る。

## 指示の解釈の進め方

0. ユーザーが ID(`faces_12` など)を言ったら、`pick_id` で引いて確認し、3 へ進む。ID が無く「この部分」とだけ言われたら、ビューアーでその面にマウスを重ねて ID を教えてもらう。難しければ 1 へ。
1. ユーザーが「この部分」と言ったら、まず該当しそうなモデルを `faces`(必要なら `edges`)で表示し直し、画面を撮って番号が読めるか確かめる。
2. 表から該当しそうな番号を挙げて(例: 「F24 の円筒面(R10.3)のことですか」)、番号と座標で確認する。形の話か図の話かも確認する。
3. 番号が決まったら、その面を作っているコード(円筒の切り出し、穴、段など)を直す。直したら番号を振り直して表示し、前後の違いを見せる。
4. 面・辺の番号は、形を作り直すたびに変わる。修正後の番号は前のものと違うと伝える。

## 注意

- 番号は `shape.faces()` / `shape.edges()` の並び順で、再現性はあるが、形を変えると変わる。番号を記録に残すときは、モデルの版(コミット)と組にする。
- ラベルは薄い板の文字で、面の外側に置く。穴の内側などは見えにくい。見えないときは視点を変えるか、ツリーで他の部品を非表示にする。
- 面が多い形(刻印つきなど)は、`small` にまとまる分があるので、表の番号が飛ばない。しきい値を下げると、小さな面にも番号が付く。
- 日本語を含むファイルは Write/Edit で書く(ヒアドキュメントで日本語を渡さない)。
